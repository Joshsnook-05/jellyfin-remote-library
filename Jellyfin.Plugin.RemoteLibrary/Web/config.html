Remote Jellyfin Library

Synchronizes metadata and tiny stream pointers. Media stays on the remote server and is streamed on demand.

Jellyfin Enhanced: Enhanced is required for calendar badges, synced artwork, duplicate suppression, and user-written reviews. Remote reviews and reviewer profile pictures are imported every five minutes with their source server attached and are excluded from export to prevent recursive syncing. Updated Remote Library peers also reject nested remote pointers before scanning them. Remote Library does not replace Jellyfin Enhanced automatically.
